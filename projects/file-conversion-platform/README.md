# 파일 변환 플랫폼

PDF ↔ Word 변환을 중심으로 한 양산형 파일 변환 서비스 플랫폼입니다.

## 프로젝트 개요

- **목표**: 광고 수익 기반의 무료 파일 변환 서비스
- **핵심 기능**: PDF ↔ Word, 이미지 변환, 문서 압축
- **기술 스택**: Next.js + Cloudflare + Supabase
- **수익 모델**: Google AdSense + 프리미엄 구독

## 기술 아키텍처

```
Frontend (Next.js)
├── Cloudflare Pages (호스팅)
├── Cloudflare Workers (API)
└── Cloudflare R2 (파일 저장)

Backend (Supabase)
├── Edge Functions (파일 처리)
├── PostgreSQL (작업 관리)
└── Storage (임시 파일)
```

## 주요 기능

### 1차 출시 기능
1. **PDF → Word 변환**
   - 텍스트 기반 PDF 변환
   - OCR 지원 (스캔 PDF)
   - 포맷 보존

2. **Word → PDF 변환**
   - 레이아웃 보존
   - 폰트 임베딩
   - 압축 옵션

3. **기본 인프라**
   - 파일 업로드/다운로드
   - 실시간 진행률
   - 자동 파일 삭제

### 2차 확장 기능
- 이미지 → PDF 변환
- PDF 병합/분할
- 이미지 압축
- Office 문서 변환
